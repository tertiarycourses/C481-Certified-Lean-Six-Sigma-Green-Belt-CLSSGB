# C481 Certified Lean Six Sigma Green Belt (CLSSGB)

Hands-on labs for learners preparing for Certified Lean Six Sigma Green Belt practice and exam readiness.

## Course Information

- **Course Code:** C481
- **Course Title:** Certified Lean Six Sigma Green Belt (CLSSGB)
- **Duration:** 4 days / 30 hours
- **Level:** Beginner
- **Course Registration:** [Certified Lean Six Sigma Green Belt (CLSSGB)](https://www.tertiarycourses.com.sg/certified-lean-six-sigma-green-belt.html)
- **Reference:** [Lean Six Sigma Green Belt Certification Standard](https://www.sixsigmacouncil.org/lean-six-sigma-green-belt-certification-standard/)

## Labs

| Domain | Lab | Title | Focus Area |
|---|---:|---|---|
| Overview and Define | 01 | Lean Six Sigma Foundations and Project Selection | Quality, Lean, Six Sigma, DMAIC, project fit, business problem |
| Define | 02 | VOC, CTQ, SIPOC, and Project Charter | Customer needs, CTQ tree, SIPOC, SMART goal, scope |
| Measure | 03 | Process Mapping, Value Stream Mapping, and Lean Metrics | Process map, VSM, waste, cycle time, takt time, yield |
| Measure | 04 | Data Collection, Sampling, MSA, and Descriptive Statistics | Data plan, operational definitions, sampling, MSA concepts, mean, median, variation |
| Analyze | 05 | Root Cause Analysis and Graphical Analysis | Pareto, histogram, run chart, fishbone, 5 Whys, cause validation |
| Analyze | 06 | Hypothesis Testing and Regression Fundamentals | Practical hypotheses, p-value concept, correlation, regression, decision notes |
| Improve | 07 | Solution Selection, FMEA, Kaizen, and Error Proofing | Solution matrix, FMEA, Kaizen, 5S, poka-yoke, implementation plan |
| Control | 08 | SPC, Control Charts, Control Plan, and Project Handoff | SPC, control chart interpretation, control plan, response plan, final readiness |
