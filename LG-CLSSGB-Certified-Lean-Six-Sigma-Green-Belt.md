# Learner Guide: C481 Certified Lean Six Sigma Green Belt (CLSSGB)

This guide supports a 4-day Lean Six Sigma Green Belt course focused on applying DMAIC to defined improvement projects. Green Belt learners are expected to understand the method, support and lead smaller projects, use data to analyze process performance, and help sustain improvements.

## Learning Outcomes

By the end of the course, you will be able to:

- Explain quality, Lean, Six Sigma, Lean Six Sigma, and the DMAIC framework.
- Select a suitable Green Belt project and define the business problem.
- Translate Voice of the Customer into CTQs.
- Build SIPOC, project charter, process map, and value stream map artifacts.
- Create a data collection plan with operational definitions and sampling approach.
- Explain measurement system analysis and calculate basic descriptive statistics.
- Analyze root causes using Pareto, histogram, run chart, fishbone, and 5 Whys.
- Interpret basic hypothesis testing, correlation, and regression concepts.
- Select improvements using FMEA, Kaizen, 5S, and error-proofing ideas.
- Build control plans and interpret SPC/control chart signals.

## Course Flow

| Day | Focus | Labs |

| Day 2 | Measure phase | Labs 03-04 |

## DMAIC Study Path

### Define

Complete Labs 01 and 02.

Focus on project selection, problem statement, VOC, CTQ, SIPOC, SMART goal, scope, stakeholders, and project charter.

Checkpoint questions:

1. What makes a project suitable for Green Belt scope?
2. How do customer needs become CTQs?
3. What is the purpose of SIPOC?
4. What should a project charter clarify?

### Measure

Complete Labs 03 and 04.

Focus on process mapping, value stream mapping, Lean metrics, data collection, sampling, MSA concepts, and descriptive statistics.

Checkpoint questions:

1. What is the difference between process map and value stream map?
2. Why do operational definitions matter?
3. What can make collected data unreliable?
4. How do mean, median, range, and standard deviation describe a process?

### Analyze

Complete Labs 05 and 06.

Focus on root cause analysis, graphical analysis, hypothesis testing concepts, correlation, regression, and evidence-based decisions.

Checkpoint questions:

1. Which chart best shows the biggest causes?
2. How do fishbone and 5 Whys support root cause thinking?
3. What does a p-value help decide?
4. Why does correlation not prove causation?

### Improve

Complete Lab 07.

Focus on solution selection, FMEA, Kaizen, 5S, error proofing, and implementation planning.

Checkpoint questions:

1. Which solution has the best impact-effort fit?
2. How does FMEA prioritize risk?
3. Why is error proofing stronger than inspection?
4. What should be tested before full rollout?

### Control

Complete Lab 08.

Focus on SPC, control charts, control plan, response plan, standard work, handoff, and readiness review.

Checkpoint questions:

1. Which control chart fits the data type?
2. What should happen when a process is out of control?
3. Who owns the process after project handoff?
4. Which DMAIC topic needs more revision?
