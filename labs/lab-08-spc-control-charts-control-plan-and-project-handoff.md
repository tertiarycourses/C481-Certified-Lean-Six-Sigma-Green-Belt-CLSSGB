# Lab 08: SPC, Control Charts, Control Plan, and Project Handoff

## Phase

Control

## Objective

Create controls that sustain the improved process.

## Tasks

1. Identify the critical metric to monitor after improvement.
2. Choose an appropriate control chart type conceptually.
3. Interpret a sample control chart.
4. Identify out-of-control signals.
5. Create a control plan.
6. Define owner, frequency, method, and reaction plan.
7. Create standard work or checklist items.
8. Define project handoff to the process owner.
9. Create an exam readiness checklist.

## Deliverables

- Control chart interpretation
- Control plan
- Response plan
- Process owner handoff checklist
- Exam readiness notes

## Review Questions

1. How do control limits differ from specification limits?
2. What should happen when the process goes out of control?
3. Why is handoff important after project completion?
