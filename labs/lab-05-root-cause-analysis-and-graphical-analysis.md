# Lab 05: Root Cause Analysis and Graphical Analysis

## Phase

Analyze

## Objective

Use visual analysis and root cause tools to identify likely drivers of the problem.

## Tasks

1. Create a Pareto chart for defect types or delay causes.
2. Create a histogram or run chart for the key metric.
3. Stratify the data by team, step, shift, product, or customer segment.
4. Build a fishbone diagram.
5. Conduct 5 Whys on the top suspected cause.
6. Separate symptoms from root causes.
7. Identify causes that need validation with data.
8. Write an Analyze phase conclusion.

## Deliverables

- Pareto chart
- Histogram or run chart
- Stratification notes
- Fishbone diagram
- 5 Whys
- Root cause hypothesis list

## Review Questions

1. Why is Pareto analysis useful?
2. How does stratification help?
3. How do you avoid stopping at a symptom?

## Cleanup

Carry validated causes into Improve labs.
