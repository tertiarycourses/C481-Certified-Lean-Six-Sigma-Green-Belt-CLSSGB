# Lab 03: Process Mapping, Value Stream Mapping, and Lean Metrics

## Phase

Measure

## Objective

Map the current process and identify Lean metrics and waste.

## Tasks

1. Create a current-state process map.
2. Identify process inputs, outputs, and decision points.
3. Create a simple value stream map.
4. Mark value-added and non-value-added activities.
5. Identify the eight wastes of Lean.
6. Calculate or estimate cycle time, wait time, yield, and rework rate.
7. Identify the process step with the greatest improvement opportunity.

## Deliverables

- Process map
- Value stream map
- Waste analysis
- Lean metrics summary

## Review Questions

1. What is the difference between cycle time and wait time?
2. How does value stream mapping expose waste?
3. Which Lean metric best supports your project goal?

## Cleanup

Keep process maps for Analyze and Improve labs.
