# Lab 01: Lean Six Sigma Foundations and Project Selection

## Phase

Overview and Define

## Objective

Understand the DMAIC framework and select a suitable Green Belt project.

## Tasks

1. Define quality, Lean, Six Sigma, and Lean Six Sigma.
2. Describe the DMAIC phases in your own words.
3. List five improvement opportunities from a work or training scenario.
4. Score each opportunity by customer impact, business impact, feasibility, and scope.
5. Select one Green Belt project.
6. Write a problem statement.
7. Identify the key process metric.
8. Record expected benefits.

## Deliverables

- Project selection matrix
- Problem statement
- Initial metric and benefit statement

## Review Questions

1. Why should a Green Belt project be carefully scoped?
2. What is the difference between Lean and Six Sigma?
3. Why must a project have a measurable outcome?

## Cleanup

Keep the selected project for later labs.
