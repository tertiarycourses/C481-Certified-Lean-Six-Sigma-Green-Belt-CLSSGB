# Lab 02: VOC, CTQ, SIPOC, and Project Charter

## Phase

Define

## Objective

Build the core Define phase artifacts for the selected project.

## Tasks

1. Write three Voice of the Customer statements.
2. Translate each VOC into a measurable CTQ.
3. Build a CTQ tree.
4. Create a SIPOC diagram.
5. Define project scope and out-of-scope items.
6. Write a SMART goal statement.
7. Identify stakeholders and project roles.
8. Complete a project charter.

## Deliverables

- VOC table
- CTQ tree
- SIPOC
- Project charter

## Review Questions

1. How does VOC differ from CTQ?
2. Why is SIPOC useful early in a project?
3. What makes a goal statement SMART?

## Cleanup

Save Define phase artifacts.
