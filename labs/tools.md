# Lab Tools and Templates

## Required Tools

- Spreadsheet software
- Document editor
- Calculator
- Notes application

## Optional Tools

- Excel Analysis ToolPak
- Google Sheets
- Minitab
- Process mapping tool
- Whiteboard or collaboration board

## Recommended Templates

- Project selection matrix
- VOC worksheet
- CTQ tree
- SIPOC
- Project charter
- Process map
- Value stream map
- Data collection plan
- Descriptive statistics worksheet
- Root cause worksheet
- FMEA
- Solution selection matrix
- Control plan

## Sample Dataset Fields

If no dataset is provided, create a simple process dataset with:

- Date
- Process step
- Cycle time
- Defect type
- Defect count
- Rework count
- Output volume
- Team or operator
