# Lab 07: Solution Selection, FMEA, Kaizen, and Error Proofing

## Phase

Improve

## Objective

Select and plan improvements using structured Lean Six Sigma tools.

## Tasks

1. List possible solutions for validated root causes.
2. Score solutions using impact, effort, cost, and risk.
3. Select the top solution or solution set.
4. Create a simple FMEA for the target process step.
5. Identify failure modes, effects, causes, and controls.
6. Prioritize risk actions.
7. Plan a Kaizen event or improvement workshop.
8. Identify 5S and error-proofing opportunities.
9. Create an implementation action plan.

## Deliverables

- Solution selection matrix
- FMEA
- Kaizen plan
- Error-proofing idea
- Implementation action plan

## Review Questions

1. Why should solutions be tied to validated causes?
2. How does FMEA prioritize risk?
3. Why is error proofing better than inspection?

## Cleanup

Save the selected solution plan for Control.
