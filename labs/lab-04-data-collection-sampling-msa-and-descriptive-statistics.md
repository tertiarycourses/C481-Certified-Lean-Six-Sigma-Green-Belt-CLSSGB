# Lab 04: Data Collection, Sampling, MSA, and Descriptive Statistics

## Phase

Measure

## Objective

Prepare reliable data collection and summarize baseline data.

## Tasks

1. Write operational definitions for the project metric.
2. Create a data collection plan.
3. Define sampling method, sample size, and collection period.
4. Identify possible measurement system issues.
5. Explain MSA concepts for continuous or attribute data.
6. Calculate count, mean, median, minimum, maximum, range, and standard deviation.
7. Create a simple chart of the baseline data.
8. Summarize baseline process performance.

## Deliverables

- Operational definitions
- Data collection plan
- MSA notes
- Descriptive statistics worksheet
- Baseline summary

## Review Questions

1. Why are operational definitions important?
2. What can make measurement data unreliable?
3. What does standard deviation tell you about variation?

## Cleanup

Save baseline data for Analyze labs.
